### 随心一记

个人随笔信息记录



#### 只想体验这单个效果？：

1.把writeNotes文件夹弄到本地。



2.直接在powershell打开文件所在位置，敲:

`python run.py`



2.或者把writeNotes文件夹拖到编译软件里，直接运行run.py。



2.再或者只是想体验动效，直接把 frontend\index.html 里的代码复制了，然后自己本地创建个html文件黏贴进去。



3.具体细节，比如修改雨滴大小速度、云层厚度、多云效果之类的，可以修改index.html代码里 `WEATHER_SCHEMES` 的 `rain`、`cloud`、`cloudSpeed`、`cloudScale` 等数值。多云现在是单张图片云层，启动时生成一次云图，运行时只移动这张图。不明白的直接丢给ai，让他教你。



#### 可扩展点：

（1）当前只是读取所在地天气，来分成晴，多云，雨，后面还可以加入下雪，闪电之类的天气。

（2）可以根据读取到的雨天的雨的具体大小，来针对性的把雨的场景再分为小雨，中雨，大雨，效果分别对应不同的雨滴动效，这样更加真实（ `rain: 0` 时，为微小雨点，只有为负数才会没有雨滴效果）。
